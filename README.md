# 🌱 EcoTrend

E-commerce desenvolvido em React com foco na comercialização de produtos sustentáveis e ecológicos.

## Link do deploy
https://ecotrendstore.vercel.app/

## Sobre o projeto

A EcoTrend é uma loja virtual voltada para consumidores que desejam adotar hábitos de consumo mais conscientes.

A aplicação apresenta produtos sustentáveis divididos em diferentes categorias, permitindo que o usuário filtre os produtos, adicione itens ao carrinho e simule uma compra.

## Categorias

* Roupas
* Acessórios
* Beleza
* Casa
* Tecnologia

## Funcionalidades

* Exibição dinâmica dos produtos;
* Carregamento dos produtos utilizando JSON;
* Requisições assíncronas com Fetch;
* Filtro por categoria;
* Filtro por preço;
* Carrinho de compras dinâmico;
* Alteração da quantidade dos produtos;
* Remoção de produtos;
* Persistência do carrinho utilizando localStorage;
* Loading spinner durante o carregamento;
* Checkout simulado;
* Utilização de Promises;
* Tratamento de erros;
* Layout responsivo.

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/palomacordeiroluz/EcoTred-store-REACT.git
```

Entre na pasta:

```bash
cd ecotrend
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Depois acesse o endereço disponibilizado pelo Vite.


## Objetivo acadêmico

O projeto foi desenvolvido como atividade acadêmica para demonstrar conhecimentos de desenvolvimento web utilizando React e JavaScript, incluindo manipulação de eventos, armazenamento local, JSON, Fetch API, Promises e programação assíncrona.
